Results
===
Each team commits here at the end of the day, in `hackathon/results/<team>/`:
- `proposal.md` (from `participant/02-proposal-template.md`, with feedback received)
- `results.md` (from `participant/06-results-form.md`, Parts A and B)
- optional: the agent, skill and command files they built, and a copy of `logs/atlassian-audit.log`

**No tokens, no real data.** A person reads the diff and commits, with a ticket key and a `Reviewed-by:` trailer.
