Idea Card
===
Copy into the shared master-ideas document. One card per idea, 1–3 cards, about 3 minutes each. Short answers beat long ones.

```
Title:            (a verb phrase: "Draft acceptance criteria from a ticket")
Proposed by:

The pain:         What do you do today, how often, and how long does it take?
                  e.g. "Every sprint, ~6 tickets, ~30 min each to refine."

Input:            What does the agent start from? Where does it live?
                  (Jira ticket, Bitbucket PR, a repo, a log, a template)

Output:           What does a good result look like? Where would it go?
                  (a draft comment, a spec file, a branch, a table)

How would we know it is right?
                  (a test passes, a checklist, a second person, a diff against a known-good result)

What could go wrong?
                  Worst realistic mistake, and who would notice and when.

Who must approve before anything changes?
                  (the named human)

Systems it needs:   Jira / Bitbucket / repo / other
Could we try it today with sandbox data?   yes / partly / no
```

# Quick check before you submit
- [ ] It happens at least weekly.
- [ ] I can write down the steps I follow, including the exceptions.
- [ ] A person can tell right from wrong in minutes.
- [ ] A mistake is caught before it matters (draft, branch, PR).
- [ ] The inputs are reachable from Jira, Bitbucket or a repo.
